# robertwchen.com

Personal portfolio site for [robertwchen.com](https://robertwchen.com).

Built with Astro and deployed on Vercel. The site uses a quiet, text-first layout inspired by Astro Cactus, with project links, experience, skills, and downloadable resume variants.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build outputs to `dist/`.
